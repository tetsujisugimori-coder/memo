# Memo Nexus

現在のバージョンは `v0.5.0 "Bridge Update"` です。

Memo Nexusは、Markdownメモ、`[[知識リンク]]`、関連メモ、コレクション整理、ZIPバックアップに対応したブラウザ用メモ帳です。メモとコレクションは端末上の実フォルダではなく、ブラウザのIndexedDBへ保存されます。

## ロゴアニメーション

ヘッダーの `Memo Nexus` ロゴは、ページを開いたときに一度だけ短い演出を再生します。`設定` → `表示` → `ロゴアニメーション` で、日替わり（初期値）、タイプライター、Nexus接続、光の走査、オフを選べます。日替わりは端末のローカル日付から決定するため、同じ日には同じ演出になります。

ロゴをクリック、またはフォーカスして Enter / Space を押すと、タイプライター → Nexus接続 → 光の走査の順に次の演出へ切り替えて再生します。この一時的な選択は設定へ保存されず、再読み込み後は設定値（日替わりなら当日の演出）に戻ります。`prefers-reduced-motion: reduce` の環境では種類だけ切り替え、動きは再生しません。オフ設定では静的ロゴを表示します。

## エディタ演出

`設定` → `表示` → `エディタ演出` では、本文入力を4秒間止めた時にカーソルが一度だけ回転する演出を設定できます。初期値はONで、設定は端末内に保存されます。操作がないままなら、回転完了から20秒後に再び一回転します。IME変換中、文字列を選択中、ダイアログやAIパネルが開いている時、タブが非表示の時、Reduced Motionを尊重する設定が有効な時には再生しません。安全に座標を取得できない環境（モバイルやポップアウトを含む）でも通常のブラウザ標準キャレットを維持します。

## 語句リンクと色分け

本文に `[[語句]]` と書いた語句は、登録済み語句になります。同じ登録済み語句を本文に含む別メモも自動的に関連メモとして認識し、メモ一覧カード下部へ同じ語句ラベルと色を表示します。明示した語句は内部的に `explicit`、本文から見つけた語句は `automatic` として区別しますが、色はリンク種別ではなく語句そのもので決まるため、同じ語句は常に同じ色です。

本文中のすべての単語を自動リンクにはしません。少なくとも1件で `[[語句]]` と明示された語句だけが自動検出の対象です。英数字だけの語句は単語境界で照合するため、`AI` が `FAIL` の一部として一致することはありません。登録済み語句が通常本文に見つかった場合は、プレビュー上でも同じ色のクリック可能な語句リンクとして表示します。この変換は表示専用であり、本文エディタ、保存するMarkdown、IndexedDBのデータは書き換えません。コード、Markdownリンクのラベル、画像の代替文は自動リンク化しません。自動関連は保存済みメモ一覧の更新時に再計算され、本文を一文字入力するたびに全メモを検索しません。

`C` は短く誤検出しやすいため、自動検出では `C言語`、文頭・文末、空白・日本語句読点・括弧や引用符で区切られた `C`、または `Cについて`・`Cを` など助詞に続く `C` だけを対象にします。`CSS`、`ABC`、`Cドライブ`、`Cクラス`、`C++`、`C#` は対象外です。明示的な `[[C]]` は従来どおり常に明示語句として扱います。

登録済み語句が部分的に重複する場合、本文表示とカードの語句チップは長い語句を優先します。たとえば `GPT5.6` と `GPT5.6 sol` が登録されているとき、本文の `GPT5.6 sol` は表示上 `GPT5.6 sol` だけをリンク化します。一方、語句ランキングでは短い登録語句も関連として数えるため、同じ出現は `GPT5.6 sol` と `GPT5.6` の両方の件数に含まれます。明示的な `[[語句]]` は自動リンクより優先されます。

色の規則は固定です。色そのものはメモへ保存しないため、再読み込みや別メモでも同じ語句は同じ色になります。

|先頭文字|色グループ|
|---|---|
|英字 A〜G|A〜G グループ|
|英字 H〜N|H〜N グループ|
|英字 O〜T|O〜T グループ|
|英字 U〜Z|U〜Z グループ|
|数字|すべて同じ数字グループ|
|ひらがな・カタカナ|あ行、か行、さ行、た行、な行、は行、ま行、や行、ら行、わ行の先頭文字の行|
|漢字・その他|語句全体の安定した文字列ハッシュ|

英字は大文字・小文字を区別しません。ひらがなとカタカナは対応する五十音行で同じ色になります。たとえば `か / カ / が / ガ` はか行、`は / ハ / ば / バ / ぱ / パ` はは行です。小書きの `ぁぃぅぇぉ` はあ行、`ゃゅょ` はや行、`っ` はた行、`ヴ` はう・ウと同じあ行として扱います。長音符 `ー` など、表の規則に当てはまらない語頭文字は安定ハッシュへフォールバックします。

## AIアシスタント（Ollama／Gemini、任意機能）

### Codexチャット試作（公開版＋ローカルブリッジ）

Codexタブは実験的なローカル連携です。GitHub Pagesの公開版からも、同じPCで起動した `http://127.0.0.1:8787` のブリッジへ接続できます。公開URLを開くだけでは動作せず、各利用者のPCにNode.js、Codex CLI、Codexへのログイン、ブリッジ起動が必要です。`127.0.0.1`は閲覧者自身のPCを指すため、他人が公開版を開いてもあなたのPCのCodexへ接続されません。iPhoneからWindows PCの`127.0.0.1`へは接続できません。

最初に十分に長いtokenを生成し、同じPowerShellで環境変数を設定してブリッジを起動します。tokenはGit管理ファイルへ保存しません。

```powershell
$env:CODEX_BRIDGE_TOKEN = npm run --silent codex:token
$env:CODEX_BRIDGE_TOKEN
$env:CODEX_BRIDGE_ALLOWED_ORIGINS = "http://127.0.0.1:8765,http://localhost:8765,https://tetsujisugimori-coder.github.io"
npm run codex:bridge
```

2行目で表示されたtokenを、Memo Nexusの「ブリッジ接続トークン」欄へコピーしてください。PowerShellへ設定した値とMemo Nexusへ入力する値は完全に同じである必要があります。tokenはGit管理ファイル、メモ、スクリーンショットなどへ保存・公開しないでください。

PowerShellを閉じると環境変数は失われるため、次回起動時はtokenを再生成するか、別途安全に保管している値を再設定する必要があります。tokenを再生成した場合は、Memo Nexus側にも新しいtokenを入力し直してください。

公開版ではPythonのHTTPサーバーは不要です。`https://tetsujisugimori-coder.github.io/memo/`を開き、AIパネルの「Codex」タブで同じtokenを入力します。tokenはそのタブの`sessionStorage`だけに保存され、タブを閉じると消えます。メモ、IndexedDBのメモ本文、ZIPバックアップへは保存されません。ブラウザがローカルネットワークアクセスを求めた場合は、接続先が`127.0.0.1`であることを確認して許可してください。

ローカル開発版では、別ターミナルで `python -m http.server 8765 --bind 127.0.0.1` を起動し、`http://127.0.0.1:8765/`を開きます。既定のローカルOriginと公開Originは完全一致で許可されます。追加Originは`CODEX_BRIDGE_ALLOWED_ORIGINS`へカンマ区切りで指定できます。パス、空要素、`null`、http/https以外は拒否されます。ブリッジを`0.0.0.0`、LAN内IP、インターネットへ公開しないでください。

環境変数の恒久設定とWindows自動起動は今回未対応です。接続できない場合は、Codex CLIのログイン、ブリッジ起動、token一致、ブラウザのローカルネットワーク権限、公開Origin設定を順に確認してください。CORS拒否、ブリッジ停止、ブラウザ権限拒否は画面から完全に区別できない場合があります。

入力と明示添付した内容はログイン済みCodexを通じてOpenAIのサービスへ送信されます。本文・選択範囲は添付ボタンを押した時だけ送信されます。APIキーは保存せず、既存のCodex CLIログインを使います。空の一時作業ディレクトリ、`read-only`、`approvalPolicy: "never"`、コマンド側ネットワーク禁止と承認要求拒否を維持しますが、会話専用のdeveloper instructionsだけで全ツール利用を完全保証するものではありません。

ブリッジは App Server ごとに状態を分離し、`initialize` 応答後にIDなしの `initialized` 通知を送ってからスレッド操作を開始します。異常終了、RPCタイムアウト、送信失敗では該当プロセスだけを破棄し、次回の接続確認で再起動します。子プロセスの終了を待ってから、そのプロセスが所有する一時ディレクトリだけを削除します。Bearer tokenが正しく、Originが完全一致した`/chat`だけがthread開始・再開とストリーミングへ進みます。`/health`の未認証応答はブリッジ起動中かとtokenが必要であることだけを返します。

画面右端のロボットから、メモを送らない自由チャットと、明示的に選んだメモ／文章を参照するチャットを同じ画面で利用できます。AI機能は初期状態で無効であり、Ollamaが未導入・未起動でも通常のメモ機能はそのまま利用できます。

利用準備:

1. `設定` → `AIアシスタント` でプロバイダを選び、機能を有効にします。
2. Ollamaを使う場合は、[Ollama](https://ollama.com/)を別途インストール・起動し、利用するモデルを導入して接続確認、モデル選択、設定保存を行います。
3. Geminiを使う場合は、利用者自身のGemini APIキーを入力し、接続確認で取得したモデルから選択して設定保存を行います。APIキーはこの端末のブラウザのlocalStorageに保存され、Memo Nexusのソースコード・出力・チャット履歴には保存しません。PCとiPhoneなど別端末のlocalStorageは共有されないため、それぞれの端末で入力してください。共有端末では保存しないでください。

- Ollamaの標準接続先は `http://127.0.0.1:11434` です。接続できない場合は、Ollamaが起動していること、接続先、モデルが1件以上導入済みであること、ブラウザから接続が許可されていることを確認してください。GeminiはGoogle Gemini APIへHTTPSで接続し、モデル取得と生成に入力したAPIキーをHTTPヘッダーとして使用します。
- 初期の動作確認対象は、モデル名に `qwen`、`phi`、`granite` を含むQwen系・Phi系・Granite系です。大文字・小文字やタグの違いを問わず分類します。
- その他のインストール済みモデルも選択できますが、Memo Nexusでは動作未確認として表示します。
- 通常のロボットクリックでは過去の参照会話を持ち越さず、新しい `自由チャット` として `参照なし` で開きます。現在のメモ、タイトル、選択文章、過去のチャット履歴は送信しません。参照範囲は `参照なし`、`現在のメモ`、`選択した文章`、`指定したメモ`、`すべてのメモ`、`選択したコレクション` から選べます。
- AIパネルの用途は参照範囲とは別に `自由質問`、`要約`、`整理`、`翻訳` から選べます。自由質問は参照なしでも利用でき、要約・整理・翻訳は参照範囲の選択が必要です。翻訳では翻訳先を選択できます。
- 自由質問では質問・指示の入力が必須です。要約・整理・翻訳では参照内容があれば追加指示は任意で、用途プリセットだけでも実行できます。
- `このメモを要約` と `選択範囲をAIに送る` は同じAI画面を開き、起動時の本文または選択内容を固定します。AI画面を開いた後にメモや選択状態が変わっても、送信前の参照内容は意図せず切り替わりません。
- `すべてのメモ` はゴミ箱・削除済みを除く有効メモと未分類メモを対象にし、`選択したコレクション` は子・孫コレクションまで再帰的に対象にします。送信前に件数と合計本文文字数を表示します。
- 複数メモ参照の上限は本文合計100,000文字です。上限を超える場合や対象0件の場合は送信せず、メモを黙って切り捨てません。
- 各質問には送信時の参照ラベルを表示します。チャット履歴は現在のタブ内だけに保持し、参照本文全体を永続履歴へ重複保存しません。
- 参照するメモ内容は、利用者が設定して選択したAIプロバイダへ送信されます。Ollamaは設定したローカルサーバーへ送信します。GeminiはクラウドAIであり、質問・指示、選択したメモ本文・選択文章、AI用参照コンテキスト、会話履歴をGoogle Gemini APIへ送信します。Ollamaでlocalhost以外を指定した場合は外部送信の可能性を警告します。
- Geminiの生成は `streamGenerateContent` のSSE応答を順次表示します。接続・認証・権限・モデル不存在・レート制限・割り当て上限・サーバーエラーは共通の画面エラーへ分類し、停止ボタンはAbortControllerで通信を中断します。自動テストではGemini APIへ実接続せず、通信をモックしています。
- Geminiの接続確認は、モデル一覧だけで完了しません。選択モデルに対して短い非ストリーミング生成を実行してから送信可能にします。モデルを変更した場合は再確認が必要です。Geminiはテキスト生成対応モデルのみを一覧に表示し、安定版、Preview、Experimentalで分けます。Ollamaの「動作未確認」表示はGeminiへ適用しません。
- `config.js`、GitHub Pagesに配信するフロントエンド環境変数、リポジトリへ置く設定ファイルにはAPIキーを保存しません。静的サイトの配信ファイルに含めた値は秘密情報として扱えないためです。
- Geminiの料金・無料枠・レート制限・利用条件は固定記載せず、Google側の最新条件を確認してください。
- iPhone Safariでは、GitHub PagesからのCORS通信、localStorageの保存・復元、プライベートブラウズの保存制限、SSEストリーム、AbortController、再読み込み、ホーム画面追加の実機確認は未実施です。動作を保証するものではありません。
- 回答はストリーミング表示され、生成中にパネルを閉じても処理を継続します。停止すると受信済みの文章を残します。タブを閉じた場合、会話や回答は永続化しません。
- 接続確認・モデル取得・生成のタイムアウトは、開始後または最後のストリーム受信から一定時間通信がない場合に発生します。継続的にチャンクを受信している生成は、全体の経過時間だけでは打ち切りません。
- AI回答は本文へ自動反映・自動保存されません。内容を確認してコピー、現在のメモのカーソル位置／本文末尾への挿入、または新規メモ保存を明示的に選んでください。回答生成時にメモを参照していなくても保存できます。
- ロボットとAIパネルはキーボード操作、ダークテーマ、狭幅表示、`prefers-reduced-motion` に対応しています。右側コンテキストパネルではコレクション、AI、メモ一覧を切り替えます。PCでは本文と右パネルを並べ、中間幅では右ドロワー、モバイルでは全画面で表示します。狭幅ドロワーは背景クリックまたは `Escape` で閉じ、背後の本文操作を抑止します。AIタブを右上の×で閉じた場合も、会話と入力内容を保ったままロボットボタンで再開できます。AIからメモ一覧へ切り替えても、メモ一覧の表示・検索状態は維持されます。

## コレクション・エクスプローラ

ツールバーの `コレクション` ボタンから、メモを階層的に整理できます。コレクションとタグは別機能で、1件のメモは1つのコレクションへ所属します。

初期コレクション:

- 歴史
- プログラミング
- IT技術
- 技術史
- 雑学
- 未分類
- ゴミ箱

基本操作:

1. `コレクション` ボタンでエクスプローラを開きます。
2. コレクション行を選択すると、新規メモの保存先になります。
3. `＋` からルートまたは選択中コレクション内へ新しいコレクションを作成できます。
4. コレクションやメモの `…` メニューから、名前変更、移動、エクスポート、削除を実行できます。
5. PCではメモやコレクションをドラッグして移動・並び替えできます。

コレクションの仕様:

- 最大5階層です。
- コレクションの件数には、直下とすべての子孫コレクションにある通常メモを含みます。
- `未分類` は削除・改名・移動できないシステムコレクションです。
- コレクション未選択、未分類選択中、ゴミ箱表示中の新規メモは未分類へ入ります。
- 既存メモは初回起動時に内容やIDを変更せず、未分類へ割り当てられます。

複数選択と移動:

- `Ctrl + クリック` で個別選択を追加・解除します。
- `Shift + クリック` で表示中メモの範囲を選択します。
- エクスプローラにフォーカスがある場合、`Ctrl + A` で表示中の通常メモを全選択します。
- 選択バーまたはドラッグ操作から、複数メモをまとめて移動できます。
- スマートフォンでは各メモの `…` メニューから移動できます。

ゴミ箱:

- 通常の削除ではメモ本体を消さず、削除日時を保存してゴミ箱へ移します。
- 復元すると同じメモIDのまま元のコレクションへ戻ります。
- 元のコレクションが削除済みの場合は未分類へ戻ります。
- `完全に削除` を実行した場合だけIndexedDBからメモを削除します。

コレクションとZIP:

- 設定画面の「完全バックアップZIP」は、通常メモ・ゴミ箱・コレクション・添付を可搬バックアップとして出力します。
- コレクションの `…` メニューから、そのコレクションとすべての子孫を個別にZIP出力できます。
- ZIP内の禁止文字は安全な文字へ置換し、同名メモには連番を付けます。
- 添付があるメモは、メモ名のフォルダ内へMarkdownと `attachments` フォルダを出力します。添付がないメモは従来どおりMarkdownだけを出力します。

## 画像・PDF添付

- メモカード下部の添付エリアから、JPEG/JPG、PNG、WebP画像とPDFを追加できます。ファイル選択、複数選択、PCでのドラッグ＆ドロップに対応し、画像はクリップボードからも貼り付けられます。
- 本文エディタへ画像を貼り付けると、カーソル位置へ `![代替テキスト](attachment://画像ID)` 形式の永続参照を挿入し、カード側の同じ位置へ画像を表示します。本文エディタへの画像ドロップも同じ保存・参照方式を使用します。
- 本文へ一時的なblob URLや画像本体を保存しません。表示時だけIndexedDBの画像BlobからObject URLを作成し、メモ切り替えやページ終了時に解放します。
- 画像は追加時に長辺最大1800px、JPEG/WebPは品質0.86を目安にブラウザ上で圧縮します。PNGは透明度と文字・線を保つためPNGのまま処理し、縮小が不要で変換後の方が大きい場合は元画像を保存します。
- PDFは再圧縮せず元データをIndexedDBへ保存し、カード下部の「開く」からブラウザ標準PDFビューアで表示します。
- 添付容量の上限は1メモあたり合計20MBです。画像は圧縮後のBlob、PDFは元のBlobの容量で判定し、複数追加で超過する場合はその追加全体を保存しません。
- 画像はサムネイルから拡大表示でき、画像とPDFは個別に削除できます。本文で参照中の画像を削除する場合は警告し、参照が残った場合もカードには安全な欠損表示を出します。メモをゴミ箱へ移しても添付は保持され、メモを完全削除したときに関連添付も削除されます。
- メモ単体、コレクション、全件の各エクスポートと、対応ブラウザでのローカルフォルダ書き出しには添付ファイルも含まれます。内部の `attachment://画像ID` は出力時だけ実ファイルへの相対パスへ変換し、アプリ内の元本文は変更しません。
- 「バックアップ／Markdown ZIP取り込み」は、従来のMarkdown ZIPに加えてMemo Nexus完全バックアップを復元できます。
- PDFの本文内埋め込みには対応せず、添付エリアからブラウザ標準ビューアで開きます。カード表示内容全体のPDF保存は将来機能です。

## 可搬バックアップ（format version 1）

完全バックアップZIPとローカルフォルダ保存は、保存先・梱包方法だけが異なる同じ論理構造を使います。

```text
manifest.json      # format: memo-nexus-backup、version: 1、出力日時
collections.json   # ID、親子関係、順序など
notes/*.md         # YAML front matter付きの通常のMarkdown本文
assets/*           # 画像・PDF添付
```

Markdownのfront matterにはメモID、タイトル、コレクションID、作成・更新日時、フラグ、ゴミ箱状態、添付情報などを保存します。Importはまずmanifestを検証し、コレクション、メモ、添付の順に復元します。IDが重複する場合は`updatedAt`が厳密に新しい方だけを採用し、同日時では既存データを維持します。不明なコレクションは未分類へ移動します。

壊れたMarkdownや欠損した添付は個別にスキップし、残りを復元します。manifestがない・壊れている・形式が異なる・アプリが理解できない将来のversionの場合は、既存データを変更せず中止します。Import結果は設定画面と保存状態に件数・スキップ内容として表示されます。将来の形式変更は、ZIPを書き換えず読み込み時のmigrationとして追加します。

表示:

- 広いPC画面ではメモ一覧を画面の最も右側へ表示します。
- 半画面、縦長画面、スマートフォンでは右から重なるドロワーとして表示します。
- ドロワーは閉じるボタン、外側クリック、`Escape` キーで閉じられます。
- ライトテーマとダークテーマに対応しています。

## フォント設定とFont Comparison連携

- 設定画面の「フォント設定」で、編集画面上部の題名フォント・題名サイズ、本文フォント・本文サイズ、見出しフォント、コードフォント・コードサイズを変更できます。
- すべてのフォント欄は「システムフォント」と「Webフォント（選択時に読込）」に分かれています。システムフォントはSegoe UI、Yu Gothic UI、Meiryo、MS Mincho、Consolas、Cascadia Code、Courier New、Times New Romanの8種です。WebフォントはNoto Sans JP、Noto Serif JP、Noto Sans SC、Noto Sans TC、Source Han Sans、Inter、IBM Plex Sans、JetBrains Mono、Zen Kaku Gothic New、Shippori Minchoの10種です。
- 既定で開く「条件からフォントを探す」は、使用言語、文章の雰囲気、主な用途から最大3件の候補を検索するアンケートです。初期回答は「日本語／中立・読みやすさ重視／長文を書く」で、設定画面を開いた時点から3件を表示し、回答変更時に自動更新します。候補表示だけでは保存もWebフォント読込も行いません。「長文を書く／読む」は本文、「見出し・短文」は見出し、「プログラミングコード」はコードの選択欄とプレビューへ反映し、「フォント設定を保存」で確定します。フォント選択欄では一覧から直接選択でき、Font Comparisonでは実際の表示を詳しく比較できます。
- 全体設定に加え、「このメモでは個別のフォント設定を使用する」を有効にすると、現在のメモだけ別の設定を保存できます。
- 全体設定はこの端末のlocalStorageへ保存し、ZIPバックアップには含めません。メモ個別設定はメモの`fontSettings`としてIndexedDB、ローカルMarkdown、ZIPバックアップを往復します。いずれもフォントIDと既存のサイズ設定だけを保存し、フォントファイルや配信CSSは保存しません。
- 各フォントの「フォントを比較して選ぶ」から `https://tetsujisugimori-coder.github.io/font-comparison/` を新しいタブで開き、現在の設定と比較文章を渡せます。比較文章は任意入力、現在のメモ本文、標準サンプルの順に使用し、URLへ含めるため最大700文字です。
- Font Comparisonとの往復は上記18種に対応します。戻り値は送信元、用途、適用範囲、登録済みフォントID、Memo Nexus側の正確な`font-family`を検証し、URL側の表示名は信頼せずローカルの正式名を使います。戻った時点では保存されず、「この設定を使用」でプレビューへ反映し、「フォント設定を保存」で確定します。
- Webフォントは起動、選択肢、条件検索の候補表示、検索条件の変更だけでは読み込みません。保存済み設定が現在の画面で使われる時、選択をプレビューへ反映した時、Font Comparisonの受取を確定した時に、必要なフォントの必要なWeightだけをGoogle FontsまたはjsDelivrから読み込みます。題名と見出しは700、本文とコードは400を要求し、同一フォントの用途はWeightを集約します。読込済みWeightは再取得せず、後から必要になった不足Weightだけを追加します。Source Han Sans CNもRegular（400）とBold（700）の必要なOTFだけを取得します。
- 題名設定は編集画面上部の題名入力欄だけに適用され、メモ一覧の題名には適用しません。そのほかのフォント設定も操作ボタン、KaTeX数式、Mermaid図の表示には適用しません。
- オフライン時や配信元からの読込に失敗した場合も、選択したIDは保持し、CSSの後続フォントで表示します。設定画面には失敗したフォントとWeight、代替表示の案内、「再試行」ボタンを表示します。再試行は現在の設定またはプレビューで必要な失敗Weightだけを要求し、読込中は重複操作を防ぎ、成功後はエラーとボタンを消します。Memo Nexusは実際に描画されたフォントを断定しません。

## 記法ガイド

- タイトル欄と本文入力欄の間にある `記法ガイド` ボタンから、現在対応しているMarkdown、KaTeX数式、計算ブロック、コードブロック、表ブロック、Mermaidの書き方を確認できます。
- 各サンプルは開始・終了のバッククォートを含む完成形でコピーできます。本文への自動挿入は行いません。
- 本文中の計算式を選択して `計算` を押すと、Calculator Memoへ式を渡して新しいタブで開けます。選択していない場合は、空のCalculator Memoを開きます。
- Markdown欄には見出し、太字・斜体・打ち消し線、箇条書き・番号付きリスト・チェックリスト、水平線、引用、通常リンク、`[[Wikiリンク]]`、注意書きを掲載しています。
- 注意書きはGitHub形式の `> [!NOTE]`、`TIP`、`IMPORTANT`、`WARNING` を本文へそのまま保存します。通常の引用とは別の色・アイコンで表示され、Markdown出力でも読めます。
- 本文内に `<!-- memo-nexus:image-block --> ... <!-- /memo-nexus:image-block -->` があると、画像を本文順に反映した画像ブロックカードとして表示されます。画像参照は `attachment://ID` のみを本文へ保存し、画像本体は添付として保持されます。
- 画像ボタン（本文編集欄の直上）で添付画像を選択すると、カーソル位置へ画像ブロックとして挿入します。カーソル位置が取得できない場合は本文末尾に追加します。
- 本文またはコードを選択して `解説` を押す、または対象選択なしの `解説` でカーソル位置へ追加すると、対象文字列・前後文脈・位置とともに解説を保存します。本文を編集し直しても、位置・完全一致・前後文脈の順に再特定し、対象不明のカードは保持して本文中の確認カードとして表示します。プレーンテキスト、太字・斜体・打ち消し線、通常リンク、インラインコードの単一階層へ対応します。`**[保存](URL)**` のような装飾の入れ子や複数の表示ノードにまたがる選択は誤った位置へ付けず孤立状態として表示します。
- 画像を本文から削除しても、添付ファイル本体は削除されません。画像の再利用が必要な場合は、画像ボタンで再度本文へ参照を追加してください。
- 通常リンクは `http`／`https` だけを新しいタブで開き、`noopener noreferrer` を付けます。チェックリストの操作は、現在開いているメモの該当項目だけを明示的に更新します。

## KaTeX数式表示

本文のMarkdownは変更せず、カード表示時だけKaTeXで数式を描画します。数式記法は表示専用であり、式の値は計算しません。

インライン数式:

```md
円の面積は $A = \pi r^2$ です。
```

ブロック数式:

```md
$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$
```

- 分数、平方根、累乗、添字、総和、積分、行列、複数行の式など、KaTeXが対応する記法を表示できます。
- 長いブロック数式は数式領域だけを横スクロールできます。
- コードブロック、インラインコード、Mermaid、計算ブロック内の数式記法はKaTeXへ渡しません。
- 不正な数式はその箇所だけ「数式を表示できません」と元の記法を表示し、他の本文やブロックの描画を続けます。

## 計算ブロック

1ブロックにつき1つの独立した式を、Calculator Memoの現在のmainと同じ規則で計算します。保存されているMarkdown本文は変更しません。

```md
:::calc
(10000 + 5000) * 1.1
:::
```

カードでは入力式を `(10,000 ＋ 5,000) × 1.1`、結果を `= 16,500` のように区別して表示します。表示用の演算記号だけを置き換え、計算には元の入力式を使用します。

対応:

- 加算、減算、乗算、除算
- 括弧、小数、負数
- `%`（Calculator Memoと同じ単項パーセント。`10%`は`10 ÷ 100`、`200 + 10%`は`200.1`）
- `＋`、`−`、`×`、`÷`、乗算としての`x`・`X`、空白の正規化

非対応:

- 累乗、`sqrt()`などの数学関数、三角関数、対数、関数電卓機能
- 変数、代入、名前付き値、複数式、複数行計算
- ブロック間参照、計算履歴参照、単位計算、数式変形、方程式、グラフ

平方根や累乗はKaTeX数式として表示できますが、現在のCalculator Memoでもこれらの高度な計算機能は未実装のため、Memo Nexusの計算ブロックでは計算できません。Memo Nexusはメモ内の簡単な計算確認に限定し、関数電卓などの高度な計算は将来的にCalculator Memo側で担当する予定です。今回はCalculator Memoリポジトリを変更していません。

- z-indexはCSS変数で一元管理し、モバイルの右側コンテキストパネルより関連メモの背景・ドロワー・ボタンを前面に配置しています。ドロワー表示中は背景オーバーレイが背面操作を遮断します。
- 関連メモボタンは右端の上側（40vh）に、AIロボットボタンは右端の下側（セーフエリア込み）に常時固定し、どちらも関連ドロワーやAIパネルを開いても操作できます。
