# Memo Nexus

AI朝刊の取り込みに対応しました。

追加機能:

- 本文中の `[[語句]]` を検出して、プレビュー下部に一覧表示します。

使い方:

1. 上部ツールバーの `設定` ボタンを押します。
2. 設定モーダルの `取り込み` から `AIニュースファイル取り込み` ボタンを押します。
3. `C:\Users\tetsu\Documents\Codex\メモ帳\IMPORT` に保存された `json` を選びます。
4. `AI朝刊 YYYY-MM-DD` という新規メモが追加されます。

補足:

- `.md` と `.txt` も取り込めます。
- `.md` や `.txt` の中に ```json ... ``` のコードブロックがあれば、その JSON を優先して朝刊メモ化します。
- AI朝刊などの取込ファイル保存先は `C:\Users\tetsu\Documents\Codex\メモ帳\IMPORT` を想定しています。
- JSONの見本は [`ai-news-template.json`](C:\Users\tetsu\Documents\Codex\メモ帳\ai-news-template.json) に置いてあります。
- オートメーション向けの出力仕様は [`ai-news-automation-format.md`](C:\Users\tetsu\Documents\Codex\メモ帳\ai-news-automation-format.md) に置いてあります。

JSON生成コード:

- 朝刊本文から取込用JSONを作るには `node build-ai-news-json.js input.md output.json` を使います。
- 入力が `.json` の場合は正規化して出力します。
- 入力が `.md` や `.txt` で、その中に ```json ... ``` があれば、そのJSONを抽出して出力します。

自動保存の状態表示:

- メモタイトル付近に自動保存の状態を表示します。
- 編集中は `編集中...`、保存処理中は `保存中...`、保存失敗時は `保存エラー` と表示します。
- 保存完了後は `保存済み: YYYY-MM-DD HH:mm:ss` の形式で、最後に保存に成功したローカル時刻を表示します。
- スマホ表示では画面幅に合わせて `保存済み HH:mm:ss` のように短縮表示します。

スマホ向けUndo:

- 上部ツールバーの `Undo` ボタンで、現在開いているメモの直前状態へ戻せます。
- Undo対象はメモID、タイトル、本文、保存時刻を持つスナップショットです。IndexedDBの保存形式や既存メモデータ構造は変更していません。
- 本文欄とタイトル欄の変更前状態を `beforeinput` で保存します。
- 削除、切り取り、貼り付け、ドロップはすぐにUndo履歴へ保存します。
- 通常入力は履歴が増えすぎないように約800ms間隔で保存し、連続する同一内容は保存しません。
- Undo履歴は最大50件です。
- PCの `Ctrl+Z` はブラウザ標準Undoをそのまま使います。アプリ側では `Ctrl+Z` を奪いません。
- Redoは現時点では未実装です。

iPhone保存安定化・ZIPバックアップ改善:

- 現在のアプリバージョンは `v0.3.1 "Draft Mirror"` で、PCでは関連メモ見出し直下、スマホでは左側ツールバー直下、共通で開発者コンソールに表示します。
- Safari/PWAの古い静的ファイルキャッシュを避けるため、CSSとJavaScriptの読み込みURLに更新識別子を付けています。
- 起動時に現在のURLとIndexedDBのメモ件数をコンソールへ出力し、別URL・別保存領域を確認しやすくしています。
- localStorageが利用できない場合やメモ件数が極端に少ない場合は、プライベートブラウズ、別タブグループ、Safari版とホーム画面版の保存領域の違いについて画面上に注意を表示します。
- IndexedDBへの保存と削除は、リクエスト受付時ではなくトランザクション完了後に成功扱いにします。
- 入力直後の保存漏れ対策として、現在編集中の1件だけをlocalStorageへドラフト退避します。全メモはlocalStorageへ保存しません。
- 起動時にドラフトがIndexedDBより新しい場合、または同じIDのメモがIndexedDBから消失している場合は、そのドラフトを復元します。
- 30日以上古いドラフトは復元せず削除します。メモを削除した場合は、同じIDのドラフトも削除します。
- 入力中にZIPバックアップを実行した場合は、遅延保存を先に完了させてからZIPを生成します。
- iPhone Safariやホーム画面追加版でページを閉じる、アプリを切り替える、画面をロックする場合に備え、`pagehide` と `visibilitychange` で未保存の入力を保存します。
- ZIP内のMarkdownファイルにはメモの更新日時を記録し、1979/11/30のような不正な日時表示を防ぎます。
- 同名タイトルのメモは `メモ.md`、`メモ-2.md`、`メモ-3.md` のように一意のファイル名で出力します。
- 開発者コンソールでは、保存したメモのID・タイトルと、ZIPのファイル数・ファイル名一覧を確認できます。

JSON貼り付け取り込み:

- 上部ツールバーの `設定` ボタンを押し、設定モーダルの `取り込み` から `JSON貼り付け取り込み` ボタンを押すと、ニュースJSONを貼り付けて取り込めます。
- 貼り付けたJSONは `JSON.parse()` で解析し、1つのJSONから1件のメモだけを作成します。`items` ごとの個別メモは作成しません。
- 作成するメモタイトルは `AI朝刊 2026-05-31` のように、JSONのタイトルと日付を並べた形式にします。
- 本文はAIニュースファイル取り込みに近い体裁で、`# タイトル 日付`、`日付: YYYY-MM-DD`、`1. 見出し`、箇条書き、`## 全体傾向` の形に整形します。
- `items` の見出しは `title`、`heading`、`headline`、`見出し` の順に扱い、日付や全体傾向、要約、重要性、情報源、時代、タグなどの項目名の揺れも一部吸収します。
- JSONが不正、または `items` が配列でない場合はエラーを表示し、保存しません。

設定モーダル:

- 上部ツールバーの `設定` ボタンから、保存状態、取り込み、バックアップ、表示、データ管理を確認できます。
- 保存状態には、保存方式、DB名、ストア名、メモ件数、保存容量、上限目安、使用率、アプリバージョン、現在のURLを表示します。
- `navigator.storage.estimate()` に対応しているブラウザでは、保存容量をMB表示で確認できます。
- `Markdown ZIPを書き出す` は設定モーダル内からも実行できます。従来の上部ツールバーの `ZIP` ボタンも残しています。
- 表示設定、JSON全体書き出し、全データ削除は現時点では未実装で、Coming soonまたは未実装表示にしています。
- 左カラムは検索とメモ一覧中心に整理し、AIニュースファイル取り込み、JSON貼り付け取り込み、知識レベルパネルは表示していません。

語句統計機能 (新機能):

- 本文中の `[[語句]]` を集計して、プレビュー下部に一覧表示します。
- 同じ語句が普通テキストで出現している場合もカウントします。
- 各語句について「使用回数（本文での出現回数）」と「使用メモ数（その語句を含むメモの数）」を表示します。
- 語句が未作成（同名のメモタイトルが存在しない）かどうも判定して表示します（未作成は「未作成」と表示）。
- ツールバーの `語句` ボタンで統計パネルを開閉できます。
