# Memo-Nexus Web Clipper

Chrome / Edge 共通の Manifest V3 開発版拡張です。すべて保存前の確認画面を経由します。

## クリップ方式

- **選択部分**: 選択文と出典情報を保存します。選択範囲のHTMLを取得できる場合は、その中の画像候補も本文位置とともに渡します。選択がある場合の初期値です。
- **ページ全文**: `article`、`main`、`role=main`を優先して本文を抽出し、安全なMarkdownへ変換します。本文中の画像候補は位置マーカー、alt、キャプション、元URLを保持し、取得できたJPEG/PNG/WebPを本体の確認画面へ渡します。本文と画像はURLフラグメントに載せず、本体が準備完了を通知した後に既存のorigin限定`postMessage`で渡します。
- **リンクのみ**: 本文なしで出典、URL、取得日時を保存します。選択がない場合の初期値です。
- **メモ付き**: 選択文（なければリンク情報）へ短いユーザーメモを付けます。

画像のOCR、要約、スクリーンショット取得、PDF、Safari/iPhone/iPadは対象外です。ページ全文の抽出は汎用的な候補選択であり、サイト固有の完全な再現はしません。

## 開発版のインストール

1. Memo-Nexus本体を `http://127.0.0.1:5500/` で開けるようにします（`localhost`ではなくこのURLを使います）。別のURLを使う場合は下記設定を先に変更します。
2. Chrome は `chrome://extensions`、Edge は `edge://extensions` を開き、開発者モードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を選び、この `extensions/web-clipper` フォルダを指定します。
4. 本体側の `web-clipper-config.js` に利用する拡張IDが登録されていることを確認します。
5. 本体ページを再読み込みします。

## 接続先の設定

- 拡張の開発URL・本番URL: `config.js` の `targets`
- 拡張に許可するURL: `manifest.json` の `host_permissions`
- 本体が受信を許可する拡張ID: 本体ルートの `web-clipper-config.js` の `allowedExtensionOrigins`

開発環境の既定接続先は `http://127.0.0.1:5500/` です。URLを変更する場合は、`config.js` と `manifest.json` を同じ値に更新します。拡張IDを変更した場合は本体の設定も更新します。`<all_urls>` は使いません。選択情報の取得には、ユーザーが拡張アイコンを押したタブだけに一時的に与えられる `activeTab` 権限を使います。

ページ全文の開発確認用に、`http://localhost/*` と `http://127.0.0.1/*` もhost permissionへ含めます。変更後は拡張の再読み込みが必要です。

## 動作確認

1. 任意のWebページで日本語の文章を選択し、拡張アイコンを押します。
2. ポップアップに選択有無、タイトル、URLが表示されることを確認します。
3. 接続先を選び「Memo-Nexusで確認する」を押します。
4. 本体の確認画面でタイトル、本文、コレクション、画像候補を確認します。画像は個別または全選択・全解除で保存対象を変更できます。保存前に自動保存はされません。
5. 選択なしでも同じ操作でURLクリップ候補を開けます。

本文は通常のURLパラメータへ入れません。選択した接続先の `?web-clip=1#clip=<base64url>` のフラグメントへUTF-8のbase64url形式で入れます。フラグメントはGitHub Pagesを含むサーバーへのリクエストに送信されず、本体は初回読取後にブラウザURLと履歴から削除します。旧来の`postMessage`受信経路は設定済みの `chrome-extension://<ID>` origin だけを許可したまま維持します。

## 画像の保存仕様

- ロゴ、広告、ナビゲーション、SNS、プロフィール、追跡ピクセル、小さすぎる画像を属性・周辺要素・実寸で候補から除外します。
- `currentSrc`、`srcset`、`data-src`、`data-lazy-src`、`data-original`を確認し、取得可能なHTTP(S)画像を選びます。
- 1画像5MB、最大20画像、1クリップ合計20MBです。本体保存時も既存添付の1メモ合計20MB制限を再確認します。
- JPEG、PNG、WebPだけを保存します。SVGとGIFは変換せず、確認画面で対応外として表示します。
- 保存済み画像は通常の画像ブロックと同じIndexedDB、表示、拡大、削除、エクスポートを使います。確認画面で除外した画像は本文から外し、取得または保存に失敗した画像は元位置に理由付き注記を残します。

## 制約

- 認証必須画像、期限切れURL、CORSで読み出しを許可しないCDN、`blob:` URLは取得できない場合があります。画像単位の失敗として扱い、本文保存は続行します。
- ページ全文は記事本文候補を抽出しますが、サイト固有のレイアウトを完全に再現するものではありません。
- AI要約、OCR、画像形式変換は未対応です。
- iPhone / iPad のSafari拡張には未対応です。
- 長い選択本文はブラウザやOSのURL長上限に依存します。上限を超える場合はクリップできないため、範囲を短くして再実行してください。
